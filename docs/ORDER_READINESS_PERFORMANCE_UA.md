- Менше чотирьох купованих позицій у `#RequiredItems`: збережено попередній спосіб зіставлення.
- Чотири й більше: один раз матеріалізуються релевантні ключі, власники характеристик і рядки закупівель; подальша перевірка йде по тимчасових індексованих таблицях.
- Обидві гілки заповнюють одну таблицю `#PurchaseLinks`; умови доступу, зв'язку, кількості й готовності не змінені. Поріг підібраний на перевірених вибірках, а не є універсальною гарантією оптимального плану для всіх періодів.
