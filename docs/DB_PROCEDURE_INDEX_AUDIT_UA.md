## Порядок покращень

1. На копії бази випробувати покривний індекс заголовків: (_Marked, _Date_Time) INCLUDE (_Number, _Posted). Для тестової версії процедури прибрати або змінити примусовий старий індекс: без цього новий не використовуватиметься. Не змінювати стандартний індекс 1С.
2. Окремо випробувати індекси товар/характеристика для трьох таблиць закупівель (кандидати в супровідному SQL). Для широких вибірок залишиться сканування, але вузького покривного індексу; для малих — можливий seek.
3. Після кожної зміни порівняти повний набір результатів з поточною процедурою та STATISTICS IO/TIME на однакових параметрах: дилер, менеджер, адміністратор; мала і велика вибірка. Не очищати загальний кеш сервера.
4. Окремо розібрати сортування #CalcRequests і відбір файлів. Не додавати всі індекси з Missing Index: це підказки, а не перевірені рекомендації.

SQL-кандидати не встановлено. Додаткові індекси збільшують місце і витрати запису 1С; спочатку потрібні порівняння на копії. Схему бази після оновлень конфігурації 1С потрібно перевіряти повторно.
